Guide d'utilisation

Chaque workflow est une carte : on le lance, on le lit, on le modifie

FlowPortal ouvre une page locale où l'on lance un workflow en un clic, on répond aux validations, on retrouve le résultat de chaque lancement, et on crée ou on modifie un workflow à la main ou en le décrivant à CSAgent.

Le portail s'ouvre par défaut dans le navigateur, à l'adresse localhost. L'ancienne interface de CSFlow reste disponible : ajoutez --classic (FlowPortal.exe --classic) ou cliquez sur « Interface classique » en haut de la page.

Les données restent à côté de l'exécutable : le dossier workflows/ (un fichier .yaml par carte), tmp/ (fichiers produits) et runs.jsonl (historique, 200 lancements au plus).

Les cartes

Une carte montre le titre, un résumé, la suite des étapes en un coup d'œil, des étiquettes (CSAgent, Validation humaine, MCP) et la date du dernier lancement. La barre de recherche et les filtres (« Avec CSAgent », « Validation humaine », « MCP », « Sans IA ») réduisent la liste ; les derniers lancements sont rappelés au-dessus.

Si un workflow ne peut pas partir, la carte l'indique (« Prérequis manquant ») et le panneau explique pourquoi : serveur MCP absent de mcp.json, ou variable d'environnement non définie. Les valeurs des clés ne sont jamais lues ni affichées, seulement leur présence.

Lancer et arrêter

  1. Cliquez sur une carte : le panneau s'ouvre avec les paramètres du bloc inputs: du workflow, que vous pouvez modifier avant de lancer.
  2. Lancer le workflow : chaque étape s'allume au fil de l'exécution. Une étape human_approval affiche « Votre décision est attendue » avec Approuver / Refuser ; une étape user_input affiche une zone de saisie.
  3. Arrêter interrompt tout de suite un script python, une commande shell (avec ses processus fils) ou une étape CSAgent, et libère une validation ou une saisie en attente. Les autres étapes (HTTP, MCP…) se terminent d'abord, puis le workflow s'arrête. Le lancement est enregistré avec le statut « Arrêté ».

Un seul workflow s'exécute à la fois.

Étape CSAgent arrêtéeLe portail coupe seulement sa connexion : le worker CSAgent peut poursuivre son travail de son côté.

Dicter une saisie

Une étape user_input avec voice: true propose le bouton 🎙 Dicter. Le navigateur enregistre, CSAgent transcrit, et le texte s'ajoute à la zone de saisie : relisez-le et corrigez-le avant de valider (Ctrl + Entrée).

  • Il faut un worker CSAgent démarré avec --api, comme dans l'interface classique.
  • Le micro n'est accessible que si la page est ouverte en localhost, ce qui est le cas du portail.
  • Un enregistrement peut durer jusqu'à 20 minutes ; les longs enregistrements sont transcrits par parties.

Vue liste, modifier, copier, renommer, supprimer

Le bouton Vue liste affiche les workflows en tableau : nom et fichier, nombre d'étapes, dernier lancement, prérequis manquants. Chaque ligne propose Lancer, Modifier (l'éditeur plein écran s'ouvre directement), Dupliquer, Renommer et Supprimer. La recherche et les filtres fonctionnent dans les deux vues.

Dupliquer copie le workflow sous un nouveau nom (proposé : nom-copie) et met à jour son name: pour distinguer les deux cartes. Renommer change le nom du fichier ; sa copie .bak et l'historique des lancements suivent, et le name: est mis à jour seulement s'il était identique à l'ancien nom. Renommer est refusé pendant un lancement. Ces deux actions sont aussi dans le panneau du workflow.

Supprimer demande une confirmation, puis déplace le fichier dans workflows/.corbeille/ (la date est ajoutée au nom, la copie .bak suit). Rien n'est effacé définitivement : pour récupérer un workflow, recopiez-le à la main dans workflows/. L'historique des lancements est conservé. La suppression est refusée tant qu'un lancement ou une demande à l'assistant est en cours.

Résultat d'un lancement

À la fin d'un lancement, Voir le résultat ouvre une vue plein écran (également accessible depuis « Derniers lancements » et depuis le bandeau des lancements récents) :

  • Étapes : statut, durée et sortie de chaque étape ; une étape en échec est dépliée avec son message.
  • Fichiers : les fichiers écrits par le lancement, avec un aperçu ; Ouvrir les ouvre dans l'application par défaut (les exécutables sont refusés, et seuls les fichiers du dossier de FlowPortal sont accessibles).
  • Journal : déroulé chronologique, copiable.
  • Entrées : les paramètres utilisés. Relancer rouvre le workflow et le relance avec les valeurs par défaut de ses paramètres.

Les valeurs des variables d'environnement qui ressemblent à des secrets (…KEY, …TOKEN, …SECRET, …PASSWORD) sont masquées dans l'historique, et les sorties longues sont tronquées.

Lire et modifier le YAML

Voir le YAML affiche le fichier coloré ; Modifier ouvre un éditeur, avec un mode Plein écran (numéros de ligne, liste des problèmes cliquable pour sauter à la ligne). La structure est vérifiée en continu par le moteur.

  • Enregistrer (ou Ctrl + S) n'est possible que sans erreur de validation ; l'ancienne version est gardée dans un fichier .bak et l'écriture est atomique.
  • Annuler les modifications revient au texte enregistré. Fermer sans enregistrer demande une confirmation.

Créer un workflow

Le bouton + Nouveau workflow (en haut de la liste) demande un nom de fichier — .yaml est ajouté si besoin, et un nom déjà pris est refusé — puis un point de départ :

Point de départCe que vous obtenez
VideUn squelette valide : nom, description et une étape de fin.
Une étapeUn workflow qui écrit un fichier à partir d'un paramètre.
Avec validationUn workflow où un humain approuve ou refuse avant la suite.
Décrire à CSAgentLe squelette vide, avec l'onglet Assistant ouvert pour dire ce que doit faire le workflow.

Le workflow s'ouvre dans l'éditeur plein écran, sans être enregistré : le fichier n'est créé que par Enregistrer, après validation. Fermer l'éditeur abandonne le brouillon.

L'assistant CSAgent

L'onglet Assistant de l'éditeur crée ou modifie un workflow à partir d'une demande en français, tapée ou dictée — par exemple « ajoute une étape qui écrit le résultat dans un fichier » ou « demande une validation avant l'envoi ».

Vous1. DemandezTapez ou dictez, relisez, puis « Envoyer à CSAgent » (Ctrl + Entrée).
CSAgent2. Il travaille sur une copieUn brouillon dans tmp/assist/ ; jamais le vrai fichier.
Portail3. Il valideLe résultat est contrôlé ; en cas d'erreur, CSAgent corrige (deux essais au plus).
Vous4. Vous décidezVous relisez les lignes ajoutées et supprimées, puis Appliquer ou Rejeter.
  • Appliquer dans l'éditeur remplace le texte de l'éditeur, qui reste non enregistré : enregistrez ensuite comme d'habitude. Si vous avez modifié le texte entre-temps, un second clic confirme l'écrasement.
  • Vous pouvez enchaîner plusieurs demandes : la conversation reste visible tant que l'éditeur est ouvert ; sa fermeture l'efface, ainsi que les brouillons.
  • Si CSAgent demande une confirmation (Auto-approve: OFF), elle s'affiche dans l'onglet et vous répondez par Approuver ou Refuser.
  • Arrêter coupe la connexion avec CSAgent. L'assistant et les lancements de workflows ne s'exécutent pas en même temps.
Relisez toujours la propositionLe résultat d'un modèle de langage varie d'une demande à l'autre, et un YAML valide n'est pas forcément un workflow qui fait ce que vous voulez. Exemple : sous Windows, start msedge fichier.html est valide mais échoue ; la bonne commande est start "" "fichier.html".

Limites et dépannage

SymptômeCause et remède
« Impossible de joindre FlowPortal »La page doit être ouverte par FlowPortal (FlowPortal.exe ou python app.py), pas comme un simple fichier.
L'assistant répond qu'il ne trouve pas le fichierLe worker CSAgent doit tourner sur la même machine, démarré depuis le dossier de FlowPortal (start_agent.bat / start_agent.sh).
« CSAgent n'a rien modifié »La demande était déjà satisfaite, ou CSAgent a répondu par une question : lisez sa réponse affichée dessous et reformulez.
La dictée échoueMicro refusé dans le navigateur, page non ouverte en localhost, ou worker CSAgent sans --api.
Le bouton Lancer est griséUn autre lancement (ou une demande à l'assistant) est en cours, ou un prérequis manque : le panneau le détaille.
Le YAML ne s'enregistre pasUne erreur de validation subsiste : cliquez sur le problème listé pour aller à la ligne.
